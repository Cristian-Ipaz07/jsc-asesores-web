## 📌 Visión General
Este proyecto es una plataforma web corporativa desarrollada para **JSC Asesores y Consultores**, una firma de asesoría legal y contable en Colombia. El objetivo principal fue digitalizar la presencia de la firma, centralizando su portafolio de servicios y optimizando la captación de leads mediante una arquitectura orientada a la conversión.

## 🛠️ Desafíos Técnicos y Soluciones
- **Interfaz de Alta Fidelidad:** Implementación de un diseño "Gold & Navy" utilizando **Tailwind CSS** y **shadcn/ui** para transmitir la autoridad de la firma.
- **Experiencia de Usuario Dinámica:** Integración de **Swiper.js** con lógica de bucle infinito y efectos de transición para presentar al equipo directivo de forma interactiva.
- **Optimización de Conversión:** Implementación de componentes de llamado a la acción (CTA) integrados con la API de WhatsApp para reducir la fricción en el contacto inicial.
- **Despliegue Profesional:** Configuración de entorno de producción en **Vercel** con gestión de dominios personalizados y certificados SSL.

## 📐 Estructura de Componentes
- `DirectorSection.tsx`: Carrusel interactivo con arquitectura de datos modular para el equipo jurídico y contable.
- `Navbar.tsx`: Navegación responsiva con lógica de scroll dinámico.
- `AnimatedSection.tsx`: Wrapper de animaciones de entrada utilizando *Intersection Observer*.
